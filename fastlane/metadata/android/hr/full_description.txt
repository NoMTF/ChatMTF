ChatMTF 是一个轻亮、简洁的自定义 API 聊天助手，面向需要长期记忆、可控模型路由和本地优先体验的用户。

核心体验是普通聊天：白底界面、低饱和粉蓝配色、清晰输入框和自然消息气泡。互动 UI 作为高级实验功能默认关闭，主界面专注于稳定、快速、可读的对话。

ChatMTF 支持跨对话长期记忆。它可以记住你的偏好、项目背景、长期目标和已解决问题，让每次新对话都延续上下文，而不是从零开始。

你可以连接 OpenAI 兼容接口、云端模型、本地模型服务和多种提供商。多个服务可按优先级排列，出现故障时自动尝试备用服务，减少中断。

Soul 系统提示不再限制 4000 字。AI 可以读取、追加、覆盖或重置自己的 Soul，用来维护稳定人格、边界、长期工作方式和重要偏好。

内置工具能力包括记忆、任务、MCP、沙盒、网页访问、邮件、短信、通知、日历、语音和附件处理。Android 版本加入本地 SQLite 存储基础，并保留敏感密钥在加密设置中。

OCR 设置允许你自定义 OCR 服务实例、模型 ID 和 OpenAI 兼容 OCR endpoint。图片和 PDF 附件可先提取文字，再作为上下文发送给聊天模型；OCR 失败时会回退原附件流程。

ChatMTF 不提供广告，不内置第三方推广。API 调用直达你配置的服务，聊天数据优先保存在本地设备中。
